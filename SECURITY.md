# Security policy

## Reporting a vulnerability

Please do not open a public issue for an unpatched vulnerability or include private resume data in a report.

Use GitHub private vulnerability reporting:

https://github.com/exolithelabs/resuflow/security/advisories/new

Include the affected version, operating system, reproduction steps, and expected impact. Use synthetic test data only.

## Supported versions

Before the first stable release, security fixes are provided on the latest published release only. Users should update to the newest version before reporting an issue that may already be resolved.
